# Triage labels

The five canonical roles use their default names directly as GitHub Issues labels.

| Label | Meaning |
| --- | --- |
| `needs-triage` | The maintainer needs to evaluate the issue |
| `needs-info` | More information is expected from the reporter |
| `ready-for-agent` | The issue is specified well enough for an autonomous agent |
| `ready-for-human` | Requires a human implementation |
| `wontfix` | The issue will not be addressed |
